# Power BI Dashboard Full Screen

Página HTML para exibir um dashboard do Power BI em tela cheia, ocupando 100% da largura e altura da janela, com ajustes para ocultar as bordas e a barra inferior.

## Como utilizar
1. Copie o link público do dashboard do Power BI.
2. Cole o link no atributo src do iframe.
3. Abra o arquivo HTML no navegador.


HTML
<iframe src="SEU_LINK_PUBLICO" allowfullscreen></iframe>


## Tecnologias
- HTML5
- CSS3
- Microsoft Power BI
